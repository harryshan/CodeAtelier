# CodeAtelier

**在浏览器里描述需求，让 AI 帮你读代码、改代码、跑测试。**

CodeAtelier 是一个运行在本机的个人 AI 编程助手。连接模型服务、选好项目目录，就可以开始对话。它会直接操作项目文件，你可以随时查看修改和执行过程，或停止任务。

## 项目亮点

- **Windows Sandbox**：让 agent 和普通命令在专用低权限账户下运行，限制文件访问与直接联网，减少对日常系统账户的依赖。已通过持续实际使用验证，可用于日常开发。
- **不只给建议，也动手完成任务**：阅读代码、修改文件、运行测试、查看差异，还能提交和推送 Git。每一步的执行过程和结果都可以查看。
- **能并行的工作不必排队**：独立工具同时执行，需要先后顺序的操作按顺序完成。多个项目可以并行处理，同一项目的任务依次执行，避免同时改文件。
- **长任务可以接着做**：自动整理长对话，保存项目记忆和完整历史；任务中断后可手动恢复，不直接重复执行结果不明的命令。
- **支持 Skill 和 MCP**：用本地 Skill 复用工作方法，通过 MCP 接入更多工具和服务，连接由本机后端管理。
- **核心机制自己实现**：使用 TypeScript 开发，不依赖 agent 编排框架。任务循环、工具调度、上下文和权限管理都在项目内，便于理解和修改。

## 快速开始

需要 **Node.js 24 或 26**、[项目指定版本的 pnpm](package.json)，以及支持流式响应和工具调用的 **Responses API 服务**。项目需要用到的 Git、编译器等工具也应在本机安装。

### 1. 安装依赖

取得源码后，在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
```

### 2. 配置模型

复制 [`.env.example`](.env.example) 为 `.env`，填入服务地址、完整模型名和密钥。已有 `.env` 时直接编辑，不要覆盖。以下均为占位值：

```dotenv
CODEATELIER_BASE_URL=https://api.example.com/v1
CODEATELIER_MODEL=YOUR_MODEL_ID
CODEATELIER_API_KEY=YOUR_API_KEY
```

需要的是 Responses API，并非所有“OpenAI 兼容”服务都支持。辅助模型、思考等级等可选设置见 [配置说明](docs/development.md#配置)。

### 3. 启动并开始对话

```sh
pnpm build
pnpm start
```

浏览器打开 `http://127.0.0.1:4142`，输入本机项目目录，点击 **连接项目并新建对话**。可以先试试：

> 看看这个项目怎么启动、怎么测试，先不要修改文件。

或者给它一个具体任务：

> 修复这个错误，补上回归测试，完成后告诉我改了哪些文件、测试是否通过。

在 **模型与设置** 中可以调整运行偏好；API 地址和模型名需修改 `.env`，然后重启或重载服务。

## Windows Sandbox

启用后，agent 和普通命令使用专用低权限账户运行，而不是直接使用你的日常系统账户。文件权限和联网限制由 Windows 机制执行，不只靠提示词约束。

Sandbox 默认关闭。首次使用需要 Windows C++ 构建环境和管理员安装，完成后设置 `CODEATELIER_SANDBOX_ENABLED=true` 并重启服务。具体步骤见 [安装与使用指南](docs/windows-sandbox-guide.md)。

Git、MCP 和经审批在沙箱外执行的命令仍使用你的系统账户权限。沙箱不保证文件访问和各会话之间完全隔离；启动前检查失败时可能提示后改用普通模式，请留意任务的实际执行状态。完整限制见 [安全边界](docs/windows-integrity-sandbox.md)。这套沙箱仅适用于 Windows，macOS/Linux 使用普通本机执行模式。

## 日常使用

- **继续聊或另开一题**：原会话可以追问，项目名称右侧的 **＋** 可以新建对话。历史保存在本机，重启服务后仍可查看。
- **离开页面或停止任务**：关掉页面不会停止后台任务。可以在界面取消任务，或通过侧栏“关闭服务”及终端 `Ctrl+C` 退出；中断任务可手动恢复。
- **同时处理多个项目**：默认最多运行 2 个项目的任务，可在设置中调为 1～4；同一项目依次执行。
- **添加技能和外部工具**：按 [Skill 指南](docs/skills.md) 添加 `SKILL.md`，或按 [MCP 指南](docs/mcp.md) 配置服务并填写 `description`。模型会直接看到技能和已启用 MCP 服务的名称、用途，根据任务按需选择；MCP 配置修改后须重启或重载后端，不会为展示目录提前连接服务。

### 查阅已有对话与 Task

点击主界面侧栏 **“对话阅读器”**，或打开 `http://127.0.0.1:4142/?view=replay`（自定义端口时使用实际服务地址）。阅读器由现有 Web 服务提供，无需额外启动服务器或生成独立 HTML。

阅读器默认直接读取当前服务数据库：选择 **对话 → Task**，即可按模型调用查看工具、输入输出和历史事件，支持搜索、状态筛选和分页。不需要先导出 JSON；可筛选对话并手动刷新正在执行的 Task，刷新页面会恢复 URL 中的记录选择。访问密码与会话校验沿用主服务，查看不会重新执行任务。

旧 JSON 可切换到“本地 JSON”导入，文件不上传。首次升级这个数据库阅读功能后，请在当前任务结束后重载/重启服务以启用新增 API（仅刷新旧前端不够）。开发模式使用 `http://127.0.0.1:5173/?view=replay`。

详细操作与可选的旧单文件导出见 [Replay Case 阅读指南](docs/replay-cases.md#可视化阅读)。

## 使用前须知

- **直接改文件，没有一键回滚。** 请用 Git 或备份保留重要内容；取消任务不会撤销已发生的修改。只在可信项目中使用，遇到人工审批时先看清操作内容。Git 推送也需要审批。
- **本机运行不等于离线。** 任务所需的对话、代码片段和工具结果会发送给你配置的模型服务。不要提交 `.env`、密钥或含敏感内容的历史记录。
- **默认仅本机访问，不面向公网。** 如需受信任局域网访问，请先阅读 [访问配置](docs/development.md)，设置访问密码并限制网络访问。

当前仍是单 agent，只读 subagent 尚未开放。各平台和功能的实际测试情况见 [验证记录](docs/verification.md)。

## 参与开发

技术栈：TypeScript、Node.js、React/Vite、Fastify、SQLite、Pino。

完成依赖安装和模型配置后，在两个终端分别运行：

```sh
pnpm dev      # 后端
pnpm dev:web  # 前端，需另开终端
```

开发界面为 `http://127.0.0.1:5173`。不要与 `pnpm start` 同时占用后端端口。

- `pnpm check`：类型、代码风格、单元/回归测试和测试构建。
- `pnpm test:e2e`：浏览器交互测试，首次需运行 `pnpm exec playwright install chromium`。

默认测试不需要真实模型密钥。Evaluation 仅手动运行，不包含在默认测试或 CI 中。贡献前请阅读 [开发约定](AGENTS.md) 和 [测试说明](docs/testing.md)。
