# 自举开发验收

这是手动运行、使用真实模型的开发验收，不是产品新增工具，也不进入默认 CI。模型会读取隔离副本中的项目源码、测试和文档，并将读取内容发送至配置的模型服务；用户已明确授权使用自己的转发服务发送本次验收所读取的项目源码、测试和文档。

## 运行

```powershell
# 无需密钥，不调用模型：创建副本并复现注入缺陷
pnpm exec tsx scripts/bootstrap-agent.ts --prepare-only

# 已配置 CODEATELIER_API_KEY 后，执行真实模型验收
node --env-file=.env --import tsx scripts/bootstrap-agent.ts
```

脚本从当前 HEAD 复制跟踪文件，不复制真实 .env、历史、日志或 Git 元数据。结果保留在 .local/bootstrap-*/，不自动合并回主工作区。node_modules 链接到本机依赖，测试与工具仍具有进程权限；副本不是操作系统沙箱。只适用于可信的本项目源码。

## 固定任务与判定

1. 在副本中注入配置更新的端点后缀规范化错误，先由原有测试确认失败。
2. 要求 CodeAtelier 阅读约定、复现、修复，追加构造函数环境变量规范化测试，并更新开发文档。
3. 第一次 edit_file 成功后取消任务，关闭引擎和 SQLite，再重新打开历史并人工恢复。每阶段最多等待十分钟，不循环重启。
4. 只预授权副本工作区中一条精确的 Node 配置测试命令文本；执行器内部负责 shell 及工作目录，其他审批全部拒绝。允许修改范围为配置实现、配置测试和开发文档，结束时审查其他改动和新增文件。
5. 检查任务完成、命令成功、恢复事件、文档修改、测试数量增长，并用原始测试独立复验。再临时注入构造路径回归，要求新增测试能够检测，随后恢复源码。

本轮针对一个预先定位到配置领域的小任务，有明确测试命令。不能据此推断复杂需求、自主选测试、完整 Web UI 或所有平台的自举能力。中断是在同一进程重建引擎和存储，不模拟断电或操作系统崩溃。

## 产物

- report.json：源码版本、模型、平台、任务与检查结果。
- baseline.txt、agent-tests.txt、independent-tests.txt、mutation-tests.txt：测试证据。
- data/history.sqlite：完整会话、工具结果和恢复记录。
- data/logs/app.log：分级诊断日志，不打印逐 token 内容。
- workspace/：保留模型修改的副本供审核。

退出码 0 表示自动判定通过；仍需人工审核新增测试含义、文档准确性和 diff。不要把未完成的模型验收写成成功。
