## 2. 第一版建议范围（待确认）

已确认个人使用、Web UI 和全平台方向。建议以单 agent 实现以下完整闭环，具体能力清单待确认：

1. 用户通过 Web UI 指定工作目录并输入任务。
2. agent 读取和搜索相关代码，按需调用模型与工具。
3. 在批准的权限范围内修改文件并运行验证命令。
4. 根据工具结果继续处理，直到完成、需要用户输入或达到限制。
5. 输出变更说明、验证证据和未完成事项，允许查看 diff。

已确认第一版保存历史对话并支持重新查看。具体存储格式、位置、工具记录范围与历史管理功能待设计。

候选必需能力：文件读取、代码搜索、补丁编辑、受控命令执行、工具结果反馈、取消、超时和循环步数上限。

Web UI 候选能力：任务输入、流式回复、工具执行状态、diff 查看、权限确认、取消任务及验证结果展示。

建议第一版暂不包含多 agent 编排、原生桌面客户端、浏览器自动化、向量数据库、插件市场、远程执行平台。是否采纳由用户决定。

## 3. 技术与目录建议（待确认）

- 建议 Node.js + TypeScript strict 模式，具体版本和包管理器在实施前确定。
- 建议单包仓库起步；第三方库用于通用基础能力，自研 agent 循环、工具协议、上下文策略和授权机制。
- 已确认采用本机浏览器 Web UI + 本机后端，仅支持本机访问，服务仅监听回环地址。后端负责模型调用、文件访问和命令执行，前端展示状态并收集用户操作。
- 候选边界：API 密钥保留在后端；后端落实权限判断，并校验请求来源和会话身份。具体通信协议与断线处理方案待设计。
- 跨平台实现需处理路径、shell、进程生命周期、文件权限和编码差异；版本与浏览器矩阵确定后安排对应验证。
- 模型层保持小型接口，先落地一种 API 协议，再按实际需要扩展；不预先承诺兼容所有提供商。
- 明确最大步骤、命令超时、上下文容量和重试上限，避免无限循环或无限重试。
- 工具授权是应用逻辑，不能冒充操作系统沙箱；是否需要系统级隔离需单独决定。

候选结构（尚未创建代码目录）：

```text
src/
  web/          # Web UI、交互、状态展示
  server/       # API、事件传输、会话接入
  agent/        # 循环、停止条件、任务状态
  providers/    # 模型协议适配
  tools/        # 工具定义与实现
  permissions/  # 权限规则与确认流程
  context/      # 上下文构建与预算
  sessions/     # 历史对话持久化与读取；执行恢复待定
  config/       # 配置加载与校验
tests/          # 按行为组织验证
docs/           # 需求、架构、开发说明和决策
AGENTS.md
README.md
```

依赖方向建议：Web UI 通过 API 与 server 交互，server 调用 agent，agent 依赖工具和模型接口；核心机制不依赖 Web UI。前端不得直接导入文件访问、命令执行或密钥配置模块。共享类型靠近所属模块，避免无边界的 utils 目录。

## 4. Git 工作流建议（待确认）

区分两个问题：

- **开发本项目**：建议按文档基线、基础骨架、最小闭环、工具能力等独立可验证增量提交；每个增量同步更新文档。提交语言、Conventional Commits、分支和 PR 策略待定。
- **产品操作用户仓库**：状态与 diff 查看仍是候选能力。用户已明确，合理生成 commit 指开发本项目；产品自动 commit、push、创建 PR 不在当前已确认需求内，后续有明确需求再讨论。

## 5. 候选验收标准（待确认）

- 在受控测试仓库完成一次“理解任务 → 读取 → 修改 → 执行验证 → 汇报”的真实模型调用流程。
- 对循环与工具错误使用可重复的模拟模型测试；真实 API 验证作为单独步骤，不要求所有测试持有密钥。
- 工具失败、模型失败、命令超时和用户取消时能够停止或有界恢复，并报告真实状态。
- 未授权操作被拒绝；路径越界、链接路径和命令执行的边界有明确说明和相应验证。
- 新使用者根据 README 可完成配置并运行示例；敏感配置不会进入版本控制或默认日志。
- 修改模型协议或增加工具时，不需要重写 Web UI 与 agent 主循环。
- 在 Windows、macOS 和 Linux 的约定环境中分别验证安装、启动和编码任务闭环，记录实际验证平台与未覆盖项。
- 在 Web UI 完成任务输入、进度查看、权限确认、diff 查看和取消；刷新或断线时能准确展示任务状态，具体恢复语义待定。
- 验证 Web UI 和后端服务仅绑定回环地址，不监听局域网或公网接口；已配置的模型 API 调用正常工作。
- 保存一段对话后，刷新页面、关闭并重新打开浏览器、重启后端服务，均可在 Web UI 查看已保存的消息，保持原有内容与顺序。此项不要求自动恢复中断的工具执行。
