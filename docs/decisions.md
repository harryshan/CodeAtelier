## D024：优先采用服务公开容量和实际 token 用量

- 日期：2026-09-09
- 状态：用户要求实测，支持即实现
- 决定：发现模型元数据，以服务指定的已支持 tokenizer 估算完整输入，扣除输出预留和安全余量；保存并展示服务实报 usage，元数据不可用时退回字符模式。

- 影响：细化 D023，新增 maxOutputTokens（默认 16384），仅 token 模式发送输出上限；不猜模型容量，不把估算或累计消耗当成实时报出的窗口占用。详情见 [model-tokens.md](model-tokens.md)。
